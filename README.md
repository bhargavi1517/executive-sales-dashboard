# 📊 Executive Sales Dashboard | Power BI

## 📌 Project Overview

The Executive Sales Dashboard is a data visualization project developed using Microsoft Power BI. It presents sales information through an interactive dashboard, helping users understand business performance, explore sales trends, and make data-driven decisions.

## 🎯 Objectives

- Analyze sales data to identify trends and patterns.
- Present business information through interactive visualizations.
- Monitor sales performance using dashboard reporting.
- Support business decision-making through data analysis.
